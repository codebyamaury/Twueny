## ✨ Características Principales

- 📱 **Mockup 3D Interactivo:** Un teléfono en 3D hecho puramente con CSS que reacciona a interacciones.
- 💖 **Canvas de Partículas 3D:** Un espectacular corazón en el background formado por 200 partículas animadas en un espacio 3D usando **Anime.js** y Canvas API.
- 🌫️ **Glassmorphism:** Diseño premium con materiales de cristal para fondos de tarjetas, barras de navegación y modales de confirmación con un fuerte enfoque en desenfoque y capas.
- 🚀 **Navegación Animada:** Navbar estilo píldora con scroll progresivo, subrayado animado de secciones y botón CTA con pulso de luz (Glow Effect).
- 🖱️ **Smooth Scrolling Inteligente:** Reemplazamos el scroll nativo por una interpolación suave programada en Vanilla JS y Anime.js para una experiencia ultra fluida.

## 🎨 Sistema de Diseño

Twueny utiliza un sistema visual muy enfocado en conversiones y posicionamiento de alto valor:

- **Fondo:** `#06080F` (Espacio Profundo)
- **Marca Principal (Teal):** `#09817C` / `#2DD4BF` 
- **Acentos:** Colores de luz de neón vibrantes (`#ec4899`, `#f59e0b`, `#3b82f6`) para insignias y tarjetas.
- **Tipografías:** `Outfit` (Elegancia estructural) y `Nunito` (Para el logo logrando curvas fluidas).

---

## 🛠️ Tecnologías Usadas

Este proyecto no depende de frameworks pesados de JS, está construido desde cero para garantizar un rendimiento óptimo:

- **HTML5** semántico
- **CSS3 Vanilla** (Múltiples degradados, animaciones clave, y variables)
- **Vanilla JS** para la lógica
- [**Anime.js (v3)**](https://animejs.com/) para orquestación compleja de animaciones.
- [**FontAwesome Free (v6)**](https://fontawesome.com/) para iconografía en la UI de las cards y secciones.

## 🚀 Cómo ejecutarlo localmente

Al ser un proyecto estático en Vanilla JS/HTML/CSS, ejecutarlo es muy sencillo:

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/codebyamaury/Twueny.git
   ```

2. **Abre la carpeta:**
   ```bash
   cd Twueny
   ```

3. **Usa Live Server o un servidor local de Python:**
   ```bash
   python -m http.server 8000
   ```
4. **Visítalo en tu navegador en:** `http://localhost:8000`
